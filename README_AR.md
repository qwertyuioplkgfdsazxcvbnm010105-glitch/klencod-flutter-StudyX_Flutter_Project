# StudyX — المساعد الدراسي الشخصي (Flutter / Android)

## طريقة الحصول على APK (GitHub Actions)
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات** هذا المجلد (وليس الـ Zip نفسه). تأكد أن المجلد `.github/workflows` مرفوع.
2. افتح تبويب **Actions** ← سيعمل **Build StudyX APK** تلقائيًا (أو شغّله يدويًا Run workflow).
3. بعد انتهائه (5–10 دقائق) افتح التشغيل ← **Artifacts** ← حمّل `StudyX-apk` وفك الضغط لتجد `app-release.apk`.
4. ثبّته على الهاتف (اسمح بالتثبيت من مصدر غير معروف).

> مجلد `android/` لا يوجد في الـ Zip عمدًا؛ يتولّد تلقائيًا أثناء البناء بواسطة `flutter create`، ثم يعدّله `tools/patch_android.py` لإضافة صلاحيات المنبهات ومستقبلات إعادة التشغيل.

## البناء على جهازك (اختياري)
```
flutter create --platforms=android --org com.studyx --project-name studyx .
python3 tools/patch_android.py
flutter pub get
flutter build apk --release
```

## أول تشغيل على الهاتف (مهم للمنبهات)
- اقبل صلاحية **الإشعارات**، وفعّل **المنبهات والتذكيرات** (Alarms & reminders) للتطبيق.
- من إعدادات الهاتف ← التطبيقات ← StudyX ← البطارية: اختر **غير مقيّد**.
- من تبويب **المنبهات** اضغط **تجربة منبه (10 ث)** ثم اقفل الشاشة للتأكد أنه يرن.
- هواتف Xiaomi / Oppo / Huawei / Samsung قد تحتاج تفعيل "التشغيل التلقائي" وتعطيل تحسين البطارية.

## ما الذي يعمل
- الرئيسية: التاريخ واليوم والساعة مباشرة، نسبة الإنجاز، المهمة الحالية/القادمة والوقت المتبقي، أقرب منبه وأقرب درس، أزرار سريعة، ملخص اليوم.
- الجدول الأسبوعي (جدول مستقل لكل يوم، يُفتح يوم اليوم تلقائيًا): إضافة/تعديل/حذف/نسخ/نقل، تحذير التعارض، إظهار الوقت الفارغ، 13 نوع موعد، تنبيه قبل الموعد، تأشير الإنجاز.
- التقويم الشهري: الاختبارات والتسليم والإجازات والأيام المزدحمة ونسبة الالتزام.
- المواد والدروس (5 حالات)، المراجعة اليومية والتراكمية (تكرار متباعد 1/3/7/14/30 يومًا).
- المهام والواجبات: أولويات، حالات، تأجيل، إعادة جدولة، الوقت الفعلي، متأخرات، تنبيه قبل التسليم.
- المؤقت: مذاكرة/راحة قصيرة/راحة طويلة، مدد قابلة للتعديل، دورة تلقائية، ربط بمادة ومهمة، يعتمد على الوقت الحقيقي ويستمر مع قفل الشاشة وإغلاق التطبيق، وإشعار عند الانتهاء، وسجل جلسات.
- المنبهات: نوع/تكرار (مرة، يوميًا، أيام محددة، تاريخ محدد)، غفوة، اهتزاز، صوت منبه أو هادئ، رسالة، ربط بمهمة، تعطيل الكل، إعادة الجدولة بعد إعادة تشغيل الهاتف، إظهار حالة الصلاحيات، تجربة منبه.
- الاختبارات (الدرجة والنسبة والأخطاء وجدولة مراجعة الأخطاء)، الإحصائيات والتقارير (يومي/أسبوعي/شهري + رسم بياني + سجلات)، النوم والراحة، مركز الإشعارات وعدم الإزعاج، الإعدادات، الوضع الداكن/الفاتح، حجم الخط، RTL كامل، إعداد أول مرة، نسخ احتياطي/استعادة.
- كل البيانات محلية على الهاتف وتعمل بدون إنترنت.

## حدود النسخة الأولى (بصراحة)
- لم يُختبر هذا الكود على جهاز حقيقي ولا بُني APK من داخل هذه البيئة (لا يوجد Flutter/إنترنت فيها). اختبر قائمة الجودة على هاتفك، وإن ظهر خطأ بناء في Actions أرسل لي نص الخطأ لأصلحه.
- لم تُنفّذ بعد: الجدول السنوي، التاريخ الهجري، اختيار ملف صوت من الهاتف ومعاينة الصوت، سجل الإشعارات التي وصلت فعلًا (يعرض المجدولة فقط)، عدد مرات الغفوة، المزامنة السحابية.
- النسخ الاحتياطي عبر نسخ/لصق نص (بدون صلاحيات ملفات).
- لا توجد Foreground Service: دقة المؤقت من الوقت الفعلي + إشعار مجدول، وهذا يعمل مع قيود Android.
- الأيقونة الافتراضية أيقونة Flutter؛ يمكن استبدالها بـ flutter_launcher_icons.
- التوقيع: نسخة release موقّعة بمفتاح debug (تصلح للتثبيت المباشر وليس للنشر على Google Play).
